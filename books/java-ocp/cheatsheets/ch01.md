# Cheat sheet 1 — Dữ liệu: số, boolean, chuỗi, ngày giờ

**Primitive:** `byte`(8) `short`(16) `char`(16, không dấu) `int`(32) `long`(64, `L`) `float`(32, `f`) `double`(64) `boolean`.
Literal: `1_000`, `0x1F`, `017`, `0b101`; `_` chỉ giữa hai chữ số. Field có giá trị mặc định, biến cục bộ thì không.

| Quy tắc | Ví dụ |
|---|---|
| `byte/short/char` + … → ít nhất `int` | `byte c = a + b;` ✗ · `b += 1;` ✓ |
| Hằng compile-time vừa kiểu thì gán được | `final int k = 10; byte b = k;` ✓ · `float f = 1.0;` ✗ |
| Cast thu hẹp cắt bit / cắt phần lẻ | `(byte) 200 = -56` · `(int) -3.9 = -3` |
| Không "nới rộng rồi boxing" | `Long x = 5;` ✗ · `long y = 5;` ✓ |
| Cache `Integer` -128..127 | `==` đúng với 127, sai với 128 → dùng `equals` |
| `Long.equals(42)` | `false` (42 là `Integer`) |
| Unboxing `null` | `NullPointerException` |

**Biểu thức:** trái → phải, rồi mới ưu tiên. `i++ + ++i` (i = 5) = 12. `&&`/`||` short-circuit, `&`/`|` thì không.
`1 + 2 + "3" + 4` = `"334"`. Chia nguyên cho 0 → `ArithmeticException`; số thực → `Infinity`/`NaN`.

**Math:** `round(-2.5) = -2` (trả `long`; với `float` trả `int`) · `floor/ceil/rint` trả `double` · `abs(MIN_VALUE) < 0` ·
`floorDiv(-7,2) = -4`, `floorMod(-7,2) = 1`, `-7 / 2 = -3`, `-7 % 2 = -1` · `addExact` ném khi tràn.

**String (bất biến):** `substring(b, e)` không lấy `e` · `indexOf` → -1 · `strip()` (Unicode) vs `trim()` · `isBlank` ·
`repeat` · `split` bỏ chuỗi rỗng cuối · pool: `"ja" + "va" == "java"` ✓, biến không final + literal ✗ · `intern()`.
`compareTo`: hiệu ký tự đầu khác nhau, hoặc hiệu độ dài.

**StringBuilder (mutable):** `append/insert/delete/deleteCharAt/replace/reverse/setLength` trả về chính nó;
`equals` = so sánh tham chiếu; `substring` trả `String`.

**Text block:** `"""` + xuống dòng · bỏ thụt lề chung (tính cả `"""` đóng) · bỏ khoảng trắng cuối dòng · `\s` giữ 1 space ·
`\` cuối dòng = nối dòng · `"""` đóng riêng dòng → có `\n` cuối.

**java.time (bất biến):** quên gán lại `d.plusDays(1)` là bẫy · `LocalDate.of(2023,2,29)` → `DateTimeException` ·
31/1 + 1 tháng = 28/29/2 · `Period` (Y/M/D, `P1Y2M3D`, không tự normalize ngày) vs `Duration` (giây, `PT25H`) ·
`Period.ofYears(1).ofMonths(3)` = `P3M` (static!) · `LocalDate.plus(Duration)` → `UnsupportedTemporalTypeException` ·
DST gap: 02:30 không tồn tại → 03:30; overlap: chọn offset sớm; `plusDays(1)` giữ giờ địa phương, `plusHours(24)` giữ thời gian thật ·
`isEqual` so sánh instant, `equals` so sánh cả zone.
