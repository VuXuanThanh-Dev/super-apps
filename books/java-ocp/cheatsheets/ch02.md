# Cheat sheet 2 — Luồng điều khiển

| Switch | `case X:` | `case X ->` |
|---|---|---|
| Statement | fall-through, `break` | không fall-through |
| Expression | `yield v;` mỗi nhánh; phải đầy đủ | biểu thức / `{ … yield v; }` / `throw`; phải đầy đủ |

- Không trộn `:` và `->` trong một switch. `default` có thể ở giữa — vẫn fall-through xuống dưới.
- Selector cổ điển: `char, byte, short, int` (+ wrapper), `String`, enum. **Không** `long/float/double/boolean`.
- Nhãn cổ điển: hằng compile-time, không trùng. Java 21: `case Color.RED` (tên đầy đủ) được phép.
- **Phải đầy đủ** khi: switch expression, hoặc switch có pattern / `case null`. Đầy đủ = `default`, hoặc đủ hằng enum,
  hoặc đủ lớp con sealed, hoặc pattern không điều kiện.
- **Pattern switch:** `case Integer i when i > 0 ->`; thứ tự hẹp → rộng; case có guard trước case cùng kiểu không guard;
  `default` không được đứng trước case pattern. `null` → NPE trừ khi có `case null` (`case null, default ->`).
- **Record pattern:** `case Point(int x, var y) ->`, lồng nhau được; `instanceof Line(Point a, Point b)`.

**Flow scoping (`instanceof` pattern):**

| Viết | Biến pattern dùng được? |
|---|---|
| `if (o instanceof String s && s.isEmpty())` | ✓ vế phải |
| `if (o instanceof String s \|\| s.isEmpty())` | ✗ |
| `if (!(o instanceof String s)) return; s.length();` | ✓ sau `if` |
| `str instanceof String t` (cùng kiểu) | ✓ Java 21 (Java 17: lỗi) |

**Vòng lặp:** `for(;;)` vô hạn · `for (int i = 0, j = 5; …; i++, j--)` · for-each: biến là **bản sao** ·
`do { } while (c);` chạy ≥ 1 lần · `continue` trong `for` → update, trong `while/do` → kiểm tra điều kiện ·
`while (n++ < 3)` → n = 4 · `break LABEL`/`continue LABEL` cho vòng lồng; `break` trong switch chỉ thoát switch.

**Unreachable = lỗi:** lệnh sau `break/continue/return/throw` · sau `while(true)` không `break` · thân `while(false)`.
`if (false) { }` **không** lỗi. `if (x = 5)` với `int x` ✗; `if (b = true)` với `boolean b` ✓. `else` thuộc `if` gần nhất.
