# Cheat sheet 3 — Hướng đối tượng

**Đa hình:** method instance → theo **object** (lúc chạy). Field + method static → theo **kiểu biến** (lúc biên dịch).
Gọi method bị override từ constructor cha → field của con còn mặc định (0/null).

**Khởi tạo:** static (cha → con, một lần, theo thứ tự xuất hiện) → mỗi `new`: [cha: field/khối instance → constructor] → [con: …].
`this(...)` hoặc `super(...)` phải là dòng đầu; không cả hai. Instance initializer chỉ chạy trong constructor gọi `super`.
Viết constructor bất kỳ → mất default constructor. Cha không có no-arg → con phải `super(args)`.
Field `final` gán đúng 1 lần trong mọi constructor.

**Overload:** exact/widening → boxing → varargs; cụ thể nhất; không cái nào cụ thể hơn → ambiguous (`f(null)` với `String`/`StringBuilder`).
Chỉ khác kiểu trả về → không phải overload.

**Override:** cùng chữ ký · quyền không hẹp hơn · trả về covariant · không thêm checked exception rộng hơn ·
không override `final`/`static` (static = hiding)/`private`. `equals(MyType)` là **overload**.
Override `equals` phải override `hashCode`.

**Record:** field `private final` + accessor `x()` + `equals/hashCode/toString` (dùng field) · không field instance khác ·
ngầm `final`, không `extends` · compact constructor `R { x = …; }` gán **tham số**, không `this.x` ·
canonical constructor không hẹp quyền hơn record · constructor khác phải `this(...)` · shallow immutable.

**Nested:** static nested `new Outer.N()` · inner `outer.new I()`, `Outer.this.x` · local/anonymous: biến cục bộ effectively final.
GC: object không còn reachable; `System.gc()` chỉ là gợi ý.

**`var`:** chỉ biến cục bộ có initializer · ✗ `var x;` `var x = null;` `var a = 1, b = 2;` `var arr = {1};` `var f = () -> 1;` `var a[]` ·
✗ field, tham số, kiểu trả về · `var` không phải keyword.

**Sealed:** `sealed … permits A, B` · lớp con `final | sealed | non-sealed` (record/enum ngầm final) · cùng module/package.

**Cast:** upcast tự động · downcast sai → `ClassCastException` · lớp không liên quan → lỗi biên dịch ·
cast sang interface OK trừ khi lớp `final` không implements · `null instanceof X` = false.

**Abstract:** không `new` · method abstract không thân, không `final/private/static` · lớp cụ thể phải cài đặt hết.

**Interface:** field `public static final` · method abstract `public` · `default` · `static` (gọi `I.m()`, không kế thừa) ·
`private` · hai default trùng → phải override, `A.super.m()` · lớp thắng interface · default + abstract cùng chữ ký từ 2
interface → lỗi · functional interface: đúng 1 abstract (không tính method `Object`).

**Enum:** hằng số đứng đầu, `;` nếu có thêm thành viên · constructor ngầm private (`public` ✗) · `values()`, `valueOf`
(phân biệt hoa thường, sai → `IllegalArgumentException`), `ordinal()`, `name()`, `compareTo` · method abstract → mọi hằng phải
cài đặt · implements được, `extends` ✗, `new` ✗.
