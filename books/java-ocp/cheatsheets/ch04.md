# Cheat sheet 4 — Ngoại lệ

```text
Throwable ─┬─ Error (unchecked)
           └─ Exception (checked) ─── RuntimeException (unchecked): NPE, ArithmeticException, ClassCastException,
                                      IllegalArgumentException ← NumberFormatException, IllegalStateException,
                                      UnsupportedOperationException, IndexOutOfBounds ← ArrayIndexOutOfBounds
```

- **Checked:** handle (catch) or declare (throws). Lớp kế thừa trực tiếp `Throwable` cũng là checked.
- `try` thường cần ≥ 1 `catch` hoặc `finally`; `{}` bắt buộc; try-with-resources không cần catch/finally.
- Catch: lớp con **trước** lớp cha (ngược lại → "already been caught"). Catch checked exception mà try không thể ném → lỗi
  (trừ `Exception`/`Throwable`). Unchecked: catch thoải mái.
- **Multi-catch** `A | B e`: A, B không cha-con; `e` ngầm final.
- **try-with-resources:** `AutoCloseable`; đóng **ngược** thứ tự, **trước** catch/finally; biến ngầm final, phạm vi trong try;
  Java 9 `try (r)` với biến effectively final; tài nguyên khởi tạo lỗi → chỉ đóng các tài nguyên đã tạo;
  exception của `close()` → `getSuppressed()` của exception chính.
- **finally:** luôn chạy (trừ `System.exit`). `return x` chốt giá trị trước finally (primitive không đổi; object vẫn bị sửa).
  `return`/`throw` trong finally **thay thế** kết quả/exception (mất luôn, không suppressed).
- **Custom:** `extends Exception` (checked) / `RuntimeException` (unchecked); constructor `(String msg, Throwable cause)`.
  `getMessage()`; `toString()` = `tên.lớp.đầy.đủ: msg` (lớp lồng dùng `$`); `getCause()`.
- **Override:** được bỏ throws, ném hẹp hơn, thêm unchecked; không thêm checked mới/rộng hơn.
- **Precise rethrow:** `catch (Exception e) { throw e; }` với `e` effectively final → compiler chỉ tính exception thật của try.
- Static init lỗi → `ExceptionInInitializerError` (lần sau: `NoClassDefFoundError`).
- Không bắt → stack trace ra `System.err`, thread kết thúc.
- Lambda: chỉ ném checked exception mà method của functional interface khai báo (`Callable` được, `Runnable`/`Supplier` không).
