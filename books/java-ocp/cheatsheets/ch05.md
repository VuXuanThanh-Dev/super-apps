# Cheat sheet 5 — Mảng và Collections

**Mảng:** `new int[3]` (có size) · `new int[]{1,2}` (không size) · `{1,2}` chỉ khi khai báo · `int[] a, b[]` → b là 2 chiều ·
`a.length` · `new int[2][]` jagged · `Arrays.sort` (String: số < HOA < thường) · `binarySearch` cần sắp xếp, không thấy →
`-(chèn)-1` · `equals`/`compare`/`mismatch` · `asList`: fixed-size, `set` ghi xuống mảng, `add` ✗ · `Arrays.asList(int[])` = `List<int[]>`.

| | Thứ tự | null |
|---|---|---|
| `ArrayList`/`LinkedList` | chỉ số | ✓ |
| `HashSet` / `LinkedHashSet` / `TreeSet` | không / chèn / sắp xếp | 1 / 1 / ✗ |
| `HashMap` / `LinkedHashMap` / `TreeMap` | không / chèn / sắp xếp key | key null 1 / 1 / ✗ |
| `ArrayDeque` | hai đầu | ✗ |
| `List.of`, `Set.of`, `Map.of`, `copyOf` | bất biến | ✗ (Set/Map trùng → IAE) |

**List:** `add(i, e)` chèn · `set` thay, trả cũ · `remove(int)` vs `remove(Object)` · `subList` = view · `removeIf`, `replaceAll` ·
sửa khi for-each → thường `ConcurrentModificationException` · `Collections.unmodifiableList` = view, `List.copyOf` = bản sao.

**Set:** `add` trả `false` nếu có · TreeSet: `floor ≤`, `ceiling ≥`, `lower <`, `higher >`, `headSet(x)` <x, `tailSet(x)` ≥x,
`pollFirst` · comparator trả 0 = trùng.

**Map:** `put` trả cũ · `putIfAbsent` trả hiện tại · `getOrDefault` không thêm · `merge(k,v,f)` (f → null: xoá) ·
`compute*` · `keySet/values/entrySet` views · TreeMap: `firstKey` (rỗng → exception), `floorKey`, `headMap`, `tailMap(k, incl)` ·
key mutable bị sửa → không tìm thấy.

**Deque:** `push/pop/peek` ở **đầu** (stack) · `offer/add` **cuối**, `poll/remove/peek` **đầu** (queue) ·
exception (`add/remove/element/getFirst`) vs giá trị đặc biệt (`offer/poll/peek`).

**Sequenced (Java 21):** `addFirst/addLast/getFirst/getLast/removeFirst/removeLast/reversed()` (view) · Map: `putFirst`,
`firstEntry`, `sequencedKeySet` · bất biến → UOE.

**Sắp xếp:** `Comparable.compareTo` (tự nhiên) · `Comparator.comparing(f).thenComparing(g).reversed()` (reversed đảo phần
trước nó) · `comparingInt` · `naturalOrder/reverseOrder/nullsFirst/nullsLast` · `list.sort(null)` = tự nhiên ·
`Collections.max/min/frequency/nCopies/reverse`.

**Generics:** invariant (`List<Number> = new ArrayList<Integer>()` ✗) · `? extends T` đọc, không add (trừ null) ·
`? super T` add T, đọc ra `Object` (PECS) · không primitive · diamond chỉ sau `new` · type erasure.
