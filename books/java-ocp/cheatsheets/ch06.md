# Cheat sheet 6 — Lambda và Stream

**Lambda:** `x -> …` · `(a, b) -> …` · `(String s) -> …` / `(var s) -> …` (không trộn) · khối `{ return …; }` ·
biến cục bộ: final/effectively final (gán lại ở **bất kỳ** đâu → lỗi) · tham số không trùng tên biến cục bộ ·
`() -> { return; }` chỉ khớp void · method reference không có `()`.

| Method ref | Ví dụ |
|---|---|
| static | `Integer::parseInt` |
| object cụ thể | `System.out::println` |
| instance, object = tham số đầu | `String::length`, `String::compareTo` |
| constructor | `ArrayList::new`, `int[]::new` |

| Interface | Method | | Interface | Method |
|---|---|---|---|---|
| `Supplier<T>` | `get()` | | `Function<T,R>` | `apply` (+ `andThen`, `compose`) |
| `Consumer<T>` | `accept` (+ `andThen`) | | `UnaryOperator<T>` | `apply` |
| `Predicate<T>` | `test` (+ `and/or/negate/not`) | | `BinaryOperator<T>` | `apply` |
| `BiFunction<T,U,R>` | `apply` | | `IntSupplier` | `getAsInt` |

**Stream:** nguồn → intermediate (lười) → **một** terminal · không terminal → không chạy (kể cả `peek`) · dùng lại → `IllegalStateException` ·
từng phần tử đi hết pipeline (trừ `sorted`, stateful) · short-circuit: `limit`, `findFirst`, `anyMatch`, `takeWhile`.

**Tạo:** `Stream.of`, `Arrays.stream`, `iterate(seed, f)` (vô hạn) / `iterate(seed, hasNext, f)`, `generate`, `concat`,
`IntStream.range` (không gồm cuối) / `rangeClosed`, `Stream.of(int[])` = 1 phần tử!

**Terminal:** `toList()` (bất biến) · `collect` · `reduce(id, op)` → T · `reduce(op)` → `Optional` · `reduce(id, acc, comb)` ·
`count()` → `long` · `min/max(cmp)` → `Optional` · `findFirst/findAny` · `any/all/noneMatch` (rỗng: false/true/true) · `forEach(Ordered)`.

**Primitive:** `sum()` (int/long/double) · `average()` → **OptionalDouble** · `max()` → `OptionalInt` · `summaryStatistics` ·
`boxed`, `mapToObj`, `mapToInt` · `IntStream` không có `toList()`.

**Optional:** `of` (null → NPE), `ofNullable`, `empty` · `get/orElseThrow()` rỗng → `NoSuchElementException` ·
`orElse(x)` **luôn** tính x, `orElseGet(s)` lười · `map/flatMap/filter/or/ifPresentOrElse/stream`.

**Collectors:** `toList/toSet/toCollection` · `joining(d, p, s)` · `toMap(k, v)` trùng → ISE; `toMap(k, v, merge, TreeMap::new)` ·
`groupingBy(f)` (HashMap, key null → NPE) · `groupingBy(f, mapFactory, downstream)` · `partitioningBy(p)` luôn có false & true ·
`counting` (Long), `summingInt`, `averagingInt` (Double), `maxBy` (Optional), `mapping`, `filtering`, `flatMapping`, `teeing`.

**Parallel:** `parallelStream()` / `.parallel()`; cuối cùng `parallel/sequential` quyết định · reduce đúng khi identity trung
hoà + hàm kết hợp · nguồn có thứ tự: `collect/toList/findFirst/forEachOrdered` giữ thứ tự; `forEach/findAny` thì không.
