# Cheat sheet 7 — Module, JAR, jlink

```java
module com.shop {                         // module-info.java ở GỐC thư mục module, không có package
    requires java.sql;                    // đọc (reads) module khác
    requires transitive com.base;         // ai requires com.shop cũng đọc com.base
    requires static com.opt;              // bắt buộc lúc biên dịch, tuỳ chọn lúc chạy
    exports com.shop.api;                 // package cho mọi module
    exports com.shop.spi to com.plugin;   // qualified export
    opens com.shop.model;                 // deep reflection lúc chạy (cả private)
    opens com.shop.dto to com.fw;         // qualified opens
    uses com.shop.api.Payment;            // consumer
    provides com.shop.api.Payment with com.shop.impl.Card;   // provider (Interface with Impl1, Impl2)
}
```

- `java.base` requires ngầm (`mandated`) · không vòng requires · không split package (1 package ↔ 1 module) ·
  `exports` package rỗng/không tồn tại → lỗi · `open module` → mọi package mở, bên trong không được `opens`.
- `public` không đủ: phải `exports` · reflection private cần `opens` → không có: `InaccessibleObjectException`.
- **Service:** interface (exports) + provider (`requires api`, `provides … with …`, impl cần public no-arg constructor hoặc
  `public static provider()`, không cần export) + consumer (`requires api`, `uses`, `ServiceLoader.load(S.class)`:
  `findFirst()`, `stream()`, `iterator()`). Thiếu `uses` → `ServiceConfigurationError` **lúc chạy**. Không provider → rỗng.

| | Named | Automatic | Unnamed |
|---|---|---|---|
| Ở đâu | module path + module-info | module path, JAR không module-info | classpath |
| Tên | trong module-info | `Automatic-Module-Name` hoặc từ tên file (`my-utils-2.0.1.jar` → `my.utils`) | không có |
| Đọc | requires (+transitive) | mọi module + unnamed | mọi module |
| Export | `exports` | tất cả package | tất cả, nhưng named module không requires được |

JAR có module-info đặt trên classpath → bị coi là unnamed. **Migration:** bottom-up (thư viện lá trước) / top-down
(ứng dụng trước, thư viện làm automatic module).

| Việc | Lệnh |
|---|---|
| Biên dịch nhiều module | `javac -d out --module-source-path src -m a,b` (thêm `-p mods` nếu phụ thuộc module có sẵn) |
| Chạy | `java -p out -m mod/pkg.Main` (`--module-path`, `--module`) |
| JAR modular | `jar --create --file m.jar --main-class p.Main -C out/mod .` (`-c -f -e`); chạy `java -p dir -m mod` |
| Mô tả | `java -p out --describe-module mod` · `jar --describe-module --file m.jar` (`-d`) · `java --list-modules` |
| Phụ thuộc | `jdeps -summary x.jar` (`-s`) · `--list-deps` · `--print-module-deps` · `--jdk-internals` |
| Runtime image | `jlink --module-path out --add-modules mod --output img` (gồm phụ thuộc bắc cầu) |
