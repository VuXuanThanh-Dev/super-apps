# Cheat sheet 9 — I/O và NIO.2

| Byte | Char | Ghi chú |
|---|---|---|
| `FileInputStream` / `FileOutputStream(f, append)` | `FileReader` / `FileWriter(f, cs, append)` | mặc định ghi đè |
| `BufferedInputStream/OutputStream` | `BufferedReader` (`readLine` → null) / `BufferedWriter` (`newLine`) | |
| `DataInputStream/DataOutputStream` | — | `readInt`… hết → `EOFException`; int 4, long 8 byte |
| `ObjectInputStream/ObjectOutputStream` | — | `readObject()` ném `IOException` + `ClassNotFoundException` |
| — | `PrintWriter` / `PrintStream` | không ném IOException (`checkError`) |
| `InputStreamReader` / `OutputStreamWriter` | | cầu nối byte ↔ char, chọn charset |

`read()` → int, hết = -1 · `read(buf)` → số byte đọc · `skip`, `mark/reset` (`markSupported`), `readAllBytes`, `transferTo` ·
UTF-8: `"é"` 2 byte, `"ệ"` 3 byte · `System.console()` có thể **null**; `readPassword()` → `char[]`.

**Serialization:** `implements Serializable` · field không serializable → `NotSerializableException` · `transient`, `static`
không lưu · deserialize: constructor/initializer của lớp Serializable **không** chạy; no-arg constructor của lớp cha đầu tiên
**không** Serializable **có** chạy · `serialVersionUID` khác → `InvalidClassException` · record dùng canonical constructor ·
object dùng chung/vòng tham chiếu được giữ nguyên trong một stream.

**Path (chỉ thao tác chuỗi):** `Path.of("a","b")`, `Paths.get`, `file.toPath()` · `new Path` ✗ · `getFileName`, `getParent`,
`getRoot` (null nếu tương đối), `getNameCount`/`getName(i)` (không tính gốc), `subpath(b, e)` ·
`resolve(abs)` → abs · `relativize` trộn tuyệt đối/tương đối → IAE · `normalize()` bỏ `.` và `x/..`; `/..` → `/` ·
`equals/startsWith/endsWith` theo thành phần (`endsWith(".java")` false) · `toRealPath` cần file tồn tại.

**Files (đa số ném IOException):**
- `exists/notExists/isDirectory/isRegularFile/isSymbolicLink/isSameFile/isHidden/size`
- `createFile` (có rồi → `FileAlreadyExistsException`) · `createDirectory` (cha thiếu → `NoSuchFileException`) · `createDirectories` (không lỗi)
- `readString`, `readAllLines` (List), `lines` (Stream, **đóng**!), `writeString`, `write(p, lines)` (mỗi dòng + `\n`), `newBufferedReader/Writer`
- `copy` (đích có → FAEE trừ `REPLACE_EXISTING`), `move` (nguồn mất), `delete` (không có → NSFE; thư mục không rỗng →
  `DirectoryNotEmptyException`), `deleteIfExists` → boolean
- `list` (1 cấp, không gồm start) · `walk(start[, depth])` (gồm start) · `find(start, depth, (p, attr) -> …)`
- `readAttributes(p, BasicFileAttributes.class)`, `getLastModifiedTime`, `LinkOption.NOFOLLOW_LINKS`
- `StandardOpenOption`: mặc định ghi = `CREATE, TRUNCATE_EXISTING, WRITE`; `APPEND` không `CREATE` trên file chưa có → NSFE; `CREATE_NEW`.
