# Hướng dẫn nhanh

## Java

```java
public class Sum {
    public static void main(String[] args) {
        int total = 0;
        for (int i = 1; i <= 10; i++) total += i;
        System.out.println("Tổng 1..10 = " + total);
    }
}
```

Output:

```text
Tổng 1..10 = 50
```
