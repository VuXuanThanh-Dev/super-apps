# Chương 1 — Biến và kiểu dữ liệu

## Mục tiêu

Hiểu biến (variable) là gì và vì sao Java cần khai báo kiểu.

## Giải thích đơn giản

Biến giống một chiếc hộp có dán nhãn. Nhãn là tên biến; loại hộp là kiểu dữ liệu.
Những chữ có dấu cần kiểm tra: ắ ằ ẳ ẵ ặ ơ ư đ Ư Đ.

| Kiểu | Ví dụ | Ghi chú |
|---|---|---|
| `int` | `int tuổi = 30;` | số nguyên |
| `String` | `String tên = "Đức";` | chuỗi ký tự |

```java
int soLuong = 5; // số lượng sản phẩm
System.out.println("Đặt hàng: " + soLuong);
```
