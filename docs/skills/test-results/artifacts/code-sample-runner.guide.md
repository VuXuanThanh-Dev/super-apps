# Hướng dẫn nhanh

## Java

<!-- run -->
```java
public class Sum {
    public static void main(String[] args) {
        int total = 0;
        for (int i = 1; i <= 10; i++) total += i;
        System.out.println("Tổng 1..10 = " + total);
    }
}
```

<!-- output -->
```text
Tổng 1..10 = 55
```
